## 2. 波形采样基础

### 2.1 通道定义

HT7627S 计量芯片提供 7 通道同步采样能力：

| 通道索引 | 名称 | 物理量 | 电压等级 | 正常范围 |
|----------|------|--------|----------|----------|
| 0 | Ua | A相电压 | 220V AC | ±311V 峰值 |
| 1 | Ub | B相电压 | 220V AC | ±311V 峰值 |
| 2 | Uc | C相电压 | 220V AC | ±311V 峰值 |
| 3 | Ia | A相电流 | 取决于负载 | 0~100A |
| 4 | Ib | B相电流 | 取决于负载 | 0~100A |
| 5 | Ic | C相电流 | 取决于负载 | 0~100A |
| 6 | U0 | 零序电压 | 中性点偏移 | ±50V |

## 3. 波形数据包格式

### 3.1 数据包整体结构

**Waveform Payload 结构** (传输协议的负载部分):

```
偏移量    长度    类型        字段名              说明
─────────────────────────────────────────────────────────────────────
0        2      uint16      num_channels       通道数量 (固定为 7)
2        4      uint32      points_per_channel 每通道采样点数 (固定为 256)
6        4      uint32      cycle_seq          周波序号 (递增)
10       8      uint64      timestamp_us       时间戳 (微秒)
18       7×256×4  float32[]  channels_data      通道数据 (7168字节)
─────────────────────────────────────────────────────────────────────
总计: 2+4+4+8+7168 = 7186 字节
```

**ASCII 结构图**:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          Waveform Payload (7186 字节)                        │
├──────────┬──────────┬──────────┬──────────┬─────────────────────────────────┤
│ 2 bytes  │ 4 bytes  │ 4 bytes  │ 8 bytes  │ 7168 bytes                     │
├──────────┼──────────┼──────────┼──────────┼─────────────────────────────────┤
│ 通道数   │ 每周期   │ 周波序号 │ 时间戳   │ 7 通道 × 256 点 × 4 字节        │
│ (uint16) │ 采样点数 │ (uint32) │ (uint64) │ (float32)                      │
├──────────┼──────────┼──────────┼──────────┼─────────────────────────────────┤
│ 0x0007   │ 0x00000100│0x00000001│微秒时间  │ [Ua数据][Ub]...[U0]            │
│ (7)      │ (256)    │ (1)      │          │                                │
└──────────┴──────────┴──────────┴──────────┴─────────────────────────────────┘
   ↑        ↑          ↑          ↑          ↑
   通道数   采样点数   序号       时间戳     通道数据区
```

### 3.2 头部字段详解

#### 3.2.1 num_channels (通道数)

| 属性 | 值 |
|------|-----|
| 偏移 | 0 |
| 长度 | 2 字节 |
| 类型 | uint16 (无符号 16 位整数) |
| 字节序 | Little-Endian |
| 取值范围 | 1~16 |
| 实际值 | **7** (固定) |
| 含义 | HT7627S 同步采样的通道数量 |

**C 代码定义**:
```c
#define WS_CHANNEL_COUNT 7
// 发送时: struct.pack('<H', num_channels)
```

**Python 解析**:
```python
nc = struct.unpack_from("<H", data, 0)[0]  # 读取 uint16
# 预期: nc == 7
```

#### 3.2.2 points_per_channel (每周期采样点数)

| 属性 | 值 |
|------|-----|
| 偏移 | 2 |
| 长度 | 4 字节 |
| 类型 | uint32 (无符号 32 位整数) |
| 字节序 | Little-Endian |
| 取值范围 | 64~1024 |
| 实际值 | **256** (固定) |
| 计算公式 | 采样率 / 工频频率 = 12800 / 50 = 256 |

**C 代码定义**:
```c
#define WS_POINTS_PER_CYCLE 256
// 发送时: struct.pack('<I', points_per_channel)
```

**Python 解析**:
```python
ppc = struct.unpack_from("<I", data, 2)[0]  # 读取 uint32
# 预期: ppc == 256
```

#### 3.2.3 cycle_seq (周波序号)

| 属性 | 值 |
|------|-----|
| 偏移 | 6 |
| 长度 | 4 字节 |
| 类型 | uint32 (无符号 32 位整数) |
| 字节序 | Little-Endian |
| 取值范围 | 0 ~ 4,294,967,295 |
| 初始值 | 1 |
| 递增方式 | 每个工频周期 +1 |
| 溢出 | 自动回绕到 0 |

**用途**: 唯一标识每个周波，用于：
- 检测丢包 (序号不连续)
- 数据排序
- 关联 AI 响应

**C 代码定义**:
```c
// 发送时: struct.pack('<I', cycle_seq)
// 每次发送波形时递增
static uint32_t g_cycle_seq = 1;
```

**Python 解析**:
```python
cs = struct.unpack_from("<I", data, 6)[0]  # 读取 uint32
# 检查连续性: cs == last_seq + 1
```

#### 3.2.4 timestamp_us (时间戳)

| 属性 | 值 |
|------|-----|
| 偏移 | 10 |
| 长度 | 8 字节 |
| 类型 | uint64 (无符号 64 位整数) |
| 字节序 | Little-Endian |
| 单位 | 微秒 (μs) |
| 精度 | 1 微秒 |
| 参考时钟 | T536 本地时钟 |

**时间戳结构**:
```
┌─────────────────────────────────────────────────────────────────────┐
│                      timestamp_us (8字节)                          │
├─────────────────────────────────────────────────────────────────────┤
│  bit 63    bit 32    bit 0                                         │
│  ┌─────────────────┬─────────────────────┐                       │
│  │  秒 (高位)      │  微秒 (低位)          │                       │
│  │  10^6 秒 ≈ 116 天│  0 ~ 999999         │                       │
│  └─────────────────┴─────────────────────┘                       │
└─────────────────────────────────────────────────────────────────────┘

示例值: 1723564800500000
         ↑              ↑
         秒部分         微秒部分
         (2024-08-14)   (500000μs = 0.5s)
```

**C 代码定义**:
```c
// 获取当前时间
struct timeval tv;
gettimeofday(&tv, NULL);
uint64_t timestamp_us = (uint64_t)tv.tv_sec * 1000000ULL + (uint64_t)tv.tv_usec;

// 发送时: struct.pack('<Q', timestamp_us)
```

**Python 解析**:
```python
ts = struct.unpack_from("<Q", data, 10)[0]  # 读取 uint64

# 转换为 datetime
seconds = ts // 1_000_000
microseconds = ts % 1_000_000
datetime.fromtimestamp(seconds) + timedelta(microseconds=microseconds)
```

#### 3.3.2 float32 数据格式

**IEEE 754 单精度浮点数 (32 位)**:

```
┌─────────────────────────────────────────────────────────────────┐
│  bit 31  bit 30~23      bit 22~0                              │
│  ┌──────┬──────────────┬──────────────────────────────────────┐ │
│  │ 符号 │ 指数 (8位)   │ 尾数 (23位)                           │ │
│  │ 位   │              │                                       │ │
│  └──────┴──────────────┴──────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘

值 = (-1)^sign × (1 + mantissa) × 2^(exponent - 127)
```

**示例值**:

| 原始值 | 十六进制 | 二进制 | 解释 |
|--------|----------|--------|------|
| 220.0  | 0x435D0000 | 0 10000110 10111010000000000000000 | 正，指数=134，尾数=1.71875 |
| -311.0 | 0xC39B0000 | 1 10000111 00110110000000000000000 | 负，指数=135，尾数=1.5234375 |
| 0.01   | 0x3C23D70A | 0 01111000 01000111101011100001010 | 正，指数=120，尾数=1.0279... |
| 0.0    | 0x00000000 | 0 00000000 00000000000000000000000 | 零值 |
| NaN    | 0x7FC00000 | 0 11111111 11000000000000000000000 | 非数值（异常） |

**字节序 (Little-Endian)**:
```
float 220.0 = 0x435D0000
在内存中的字节排列: 00 00 5D 43
                     ↑  ↑  ↑  ↑
                    byte0 byte1 byte2 byte3
                     低地址 → 高地址
```

## 4. T536→RK3576 传输协议

### 4.1 协议帧结构

T536 与 RK3576 之间使用 **Protocol V2** 进行可靠数据传输。

**完整帧结构**:

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              Protocol V2 Frame                                 │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │                         Frame Header (14 字节)                          │   │
│  ├──────────┬──────────┬──────────┬──────────┬─────────────────────────────┤   │
│  │ 4 bytes  │ 1 byte   │ 1 byte   │ 4 bytes  │ 4 bytes                    │   │
│  ├──────────┼──────────┼──────────┼──────────┼─────────────────────────────┤   │
│  │ Magic    │ Version  │ Cmd      │ Seq      │ PayloadLen                 │   │
│  │ 0x574156 │ 0x02     │ 0x01     │ 12345    │ 7186                       │   │
│  │ "WV2"    │ 版本号   │ 波形帧   │ 序号     │ 负载长度                   │   │
│  └──────────┴──────────┴──────────┴──────────┴─────────────────────────────┘   │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │                         CRC32 Checksum (4 字节)                         │   │
│  ├─────────────────────────────────────────────────────────────────────────┤   │
│  │ 4 bytes: 0x8A3F2B1C                                                    │   │
│  │ (基于 Header + Payload 计算)                                            │   │
│  └─────────────────────────────────────────────────────────────────────────┘   │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │                         Payload (N 字节)                                │   │
│  ├─────────────────────────────────────────────────────────────────────────┤   │
│  │ Waveform Payload (7186 字节)                                           │   │
│  └─────────────────────────────────────────────────────────────────────────┘   │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

帧总大小 = 14 + 4 + 7186 = 7204 字节
```

### 4.2 帧头字段详解

#### 4.2.1 Magic (魔数)

| 属性 | 值 |
|------|-----|
| 偏移 | 0 |
| 长度 | 4 字节 |
| 类型 | uint32 |
| 字节序 | Little-Endian |
| 固定值 | **0x57415632** |
| ASCII 表示 | "WV2" (Wave Protocol V2) |

**用途**: 接收方快速验证数据有效性，非法魔数直接丢弃。

**C 代码**:
```c
#define PROTO_MAGIC 0x57415632
// 检查: if (header->magic != PROTO_MAGIC) discard_frame();
```

**Python 代码**:
```python
PROTO_MAGIC = 0x57415632
if header.magic != PROTO_MAGIC:
    log.warning(f"无效魔数: 0x{header.magic:08X}")
    continue
```

#### 4.2.2 Version (版本号)

| 属性 | 值 |
|------|-----|
| 偏移 | 4 |
| 长度 | 1 字节 |
| 类型 | uint8 |
| 字节序 | N/A (单字节) |
| 固定值 | **0x02** (版本 2) |

**用途**: 协议版本控制，便于未来升级。

#### 4.2.3 Cmd (命令类型)

| 属性 | 值 |
|------|-----|
| 偏移 | 5 |
| 长度 | 1 字节 |
| 类型 | uint8 |
| 字节序 | N/A (单字节) |

**命令类型表**:

| 命令值 | 名称 | 方向 | 说明 |
|--------|------|------|------|
| 0x01 | WAVEFORM | T536→RK3576 | 波形数据帧 |
| 0x02 | HEARTBEAT | 双向 | 心跳包 |
| 0x03 | ACK | 双向 | 确认包 |
| 0x04 | RETRANSMIT | 接收方→发送方 | 重传请求 |
| 0x05 | STATUS_QUERY | 双向 | 链路状态查询 |
| 0x06 | STATUS_RESPONSE | 双向 | 链路状态响应 |
| 0x07 | AI_RESULT | RK3576→T536 | AI 推理结果 |
| 0x08 | FLOW_CONTROL | 双向 | 流量控制 |

**波形帧示例**: Cmd = 0x01 (WAVEFORM)

#### 4.2.4 Seq (序列号)

| 属性 | 值 |
|------|-----|
| 偏移 | 6 |
| 长度 | 4 字节 |
| 类型 | uint32 |
| 字节序 | Little-Endian |
| 初始值 | 0 |
| 递增 | 每帧 +1 |

**用途**:
- 可靠传输确认 (ACK 机制)
- 重传检测
- 帧顺序保证

| 属性 | 值 |
|------|-----|
| 偏移 | 10 |
| 长度 | 4 字节 |
| 类型 | uint32 |
| 字节序 | Little-Endian |
| 最大值 | 65536 (64KB) |

**波形帧示例**: PayloadLen = 7186

### 4.3 CRC32 校验

| 属性 | 值 |
|------|-----|
| 偏移 | 14 (紧跟 Header) |
| 长度 | 4 字节 |
| 类型 | uint32 |
| 字节序 | Little-Endian |
| 多项式 | 0xEDB88320 |
| 初始值 | 0xFFFFFFFF |
| 计算范围 | Header + Payload (不包含 CRC 本身) |

**用途**: 数据完整性校验，检测传输过程中的数据损坏。

**C 代码实现**:
```c
#define CRC32_POLY 0xEDB88320

static uint32_t crc32_calc(const uint8_t *data, int len) {
    uint32_t crc = 0xFFFFFFFF;
    for (int i = 0; i < len; i++) {
        crc = (crc >> 8) ^ crc32_table[(crc ^ data[i]) & 0xFF];
    }
    return crc ^ 0xFFFFFFFF;
}
```

**Python 代码实现**:
```python
import zlib

frame_data = header_bytes + payload
crc32 = zlib.crc32(frame_data) & 0xFFFFFFFF
```

**CRC32 验证流程**:
```
发送方:
  1. 构建 Header
  2. 构建 Payload
  3. 计算 CRC32(header + payload)
  4. 发送: Header + CRC32 + Payload

接收方:
  1. 接收 Header + CRC32 + Payload
  2. 计算 CRC32(header + payload)
  3. 比较计算值与存储的 CRC32
  4. 一致 → 数据有效
  5. 不一致 → 丢弃，请求重传
```

## 5. RK3576→T536 AI 响应

### 5.1 AI 响应结构

AI 响应作为 Protocol V2 的 Payload 传输，命令类型为 `0x07 (AI_RESULT)`。

**AI 响应 Payload 结构** (35 字节):

```

├──────────┬──────────┬──────────┬──────────┬─────────────────────────────┤

├──────────┼──────────┼──────────┼──────────┼─────────────────────────────┤
│ Magic    │ RespType │ Timestamp│ CycleSeq │ IfScore                    │
│ 0x574156 │ 0x00     │ 微秒时间 │ 周波序号 │ iForest异常得分             │
│ 45       │ OK响应   │          │          │                            │
├──────────┼──────────┼──────────┼──────────┼─────────────────────────────┤

├──────────┼──────────┼──────────┼──────────┼─────────────────────────────┤
```

### 5.2 响应字段详解

#### 5.2.1 Magic (响应魔数)

| 属性 | 值 |

| 偏移 | 0 |

| 类型 | uint32 |
| 字节序 | Little-Endian |

| ASCII 表示 | "WAVE" (Wave AI Response) |

**用途**: 与波形帧的魔数 (0x57415632) 区分开。

#### 5.2.2 RespType (响应类型)

| 属性 | 值 |
|------|-----|
| 偏移 | 4 |

| 值 | 名称 | 含义 |
|----|------|------|
| 0 | RESP_OK | 正常，未检测到异常 |
| 2 | RESP_ANOMALY | 检测到异常 |

#### 5.2.3 Timestamp (时间戳)

与波形 Payload 中的 timestamp_us 格式相同，为 uint64 微秒时间戳。

#### 5.2.4 CycleSeq (周波序号)

与波形 Payload 中的 cycle_seq 对应，标识响应的是哪个周波。

#### 5.2.5 IfScore (iForest 异常得分)

| 属性 | 值 |
|------|-----|
| 偏移 | 13 |
| 长度 | 4 字节 |
| 类型 | float32 |
| 字节序 | Little-Endian |
| 取值范围 | 0.0 ~ 1.0 |
| 含义 | 0=正常，1=严重异常 |

**Heuristic 模式计算**:
```python
# 变异系数分数
cv_score = min(cv * 2.0, 1.0)

# 电压偏离检测
deviation_score = max_deviation * 3.0

# 三相不平衡度
unbalance_score = unbalance_pct / 50.0

# 综合得分
if_score = max(cv_score, deviation_score * 0.8, unbalance_score * 0.6)
```

#### 5.2.6 AeScore (AE 重构误差)

| 属性 | 值 |

| 偏移 | 17 |
| 长度 | 4 字节 |
| 类型 | float32 |
| 字节序 | Little-Endian |
| 取值范围 | 0.0 ~ ∞ |
| 含义 | 重构误差，越大越异常 |

#### 5.2.7 CnnConfidence (CNN 置信度)

| 属性 | 值 |
|------|-----|
| 偏移 | 21 |
| 长度 | 4 字节 |
| 类型 | float32 |
| 字节序 | Little-Endian |
| 取值范围 | 0.0 ~ 1.0 |
| 含义 | CNN 分类结果的置信度 |

#### 5.2.8 CnnClass (CNN 事件分类)

| 属性 | 值 |
|------|-----|
| 偏移 | 25 |
| 长度 | 1 字节 |
| 类型 | uint8 |

**CNN 分类表**:

| 值 | 名称 | 含义 |
|----|------|------|
| 0 | 正常 | 无异常 |
| 1 | 电压暂降 | 电压骤降 |
| 2 | 电压暂升 | 电压骤升 |
| 3 | 谐波 | 谐波超标 |
| 4 | 三相不平衡 | 三相电压/电流不平衡 |

**Heuristic 模式分类逻辑**:
```python
if if_score > 0.6:
```

## 7. 数据解析示例

### 7.1 波形帧解析示例

**接收数据 (十六进制)**:
```
45 41 56 57 | 02 | 01 | 01 00 00 00 | EA 1C 00 00 | 8A 3F 2B 1C | [Payload]
   ↑            ↑    ↑        ↑              ↑             ↑
   Magic       Version Cmd  Seq(1)      PayloadLen(7402)  CRC32
   0x57415645  0x02  0x01  0x00000001  0x00001CEA    0x1C2B3F8A
   "WV2"
```

**Payload 解析 (前 18 字节)**:
```
07 00 | 00 01 00 00 | 01 00 00 00 | 80 38 2B 72 0A 00 00 00
  ↑         ↑              ↑              ↑
  7         256            1              1723564800000000
  通道数    采样点数       周波序号       时间戳 (微秒)
```

**Python 解析代码**:
```python
import struct

# 假设 data 为接收到的波形 Payload
offset = 0

# 1. 解析通道数
num_channels = struct.unpack_from('<H', data, offset)[0]  # 读取 uint16
offset += 2
# 结果: 7

# 2. 解析每周期采样点数
points_per_channel = struct.unpack_from('<I', data, offset)[0]  # 读取 uint32
offset += 4
# 结果: 256

# 3. 解析周波序号
cycle_seq = struct.unpack_from('<I', data, offset)[0]  # 读取 uint32
offset += 4
# 结果: 1

# 4. 解析时间戳
timestamp_us = struct.unpack_from('<Q', data, offset)[0]  # 读取 uint64
offset += 8
# 结果: 1723564800000000

# 5. 解析通道数据
channels = []
for ch in range(num_channels):
    channel_data = []
    for i in range(points_per_channel):
        value = struct.unpack_from('<f', data, offset)[0]  # 读取 float32
        offset += 4
        channel_data.append(value)
    channels.append(channel_data)

# 结果: 7 个通道，每个 256 个 float32 数据点
```
