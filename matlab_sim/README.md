# 新能源与充电桩接入影响评估 - MATLAB仿真项目

## 项目概述

本项目基于MATLAB构建完整的配电台区电能质量仿真平台，采用纯MATLAB时域仿真方法（无需Simulink模型搭建），评估分布式光伏及电动汽车充电桩接入对配电网电能质量的影响。

## 技术特点

- **纯MATLAB实现**：基于电路方程和功率流分析的时域波形生成，不依赖Simulink图形建模
- **五类核心场景**：覆盖基准负荷、充电桩、光伏、光充耦合及极端高渗透率场景
- **完整指标体系**：基于GB/T国家标准计算电压偏差、THD、不平衡度、频率偏差等8项指标
- **蒙特卡洛风险评估**：量化不确定性因素下的越限概率
- **AI数据集生成**：批量生成带标签的扰动波形数据，支持AI模型训练

## 系统参数

### 配电台区模型
- **变压器**: 400kVA, 10kV/0.4kV, Dyn11, 阻抗电压4%
- **线路**: LGJ-120, 100m, R=0.027Ω, X=0.035Ω
- **负荷**: 150kW, 功率因数0.88

### 新能源设备
- **光伏**: 100kW, MPPT控制, 逆变器效率97%, 输出谐波(2/4/6/8次)
- **充电桩**: 交流7kW, 直流60kW, 充电效率95%, 输入谐波(5/7/11/13次)

## 仿真场景

| 场景 | 描述 | 评估重点 |
|------|------|----------|
| S1 | 纯常规负荷基准场景 | 建立基准电压、电流、功率分布 |
| S2 | 充电桩接入场景 | 评估谐波注入、负载率上升、电压偏差 |
| S3 | 分布式光伏接入场景 | 评估电压抬升、反向潮流、光伏谐波 |
| S4 | 光充耦合接入场景 | 评估耦合效应、综合谐波、功率因数 |
| S5 | 极端天气/高渗透率场景 | 评估高比例新能源下的承载边界 |

## 电能质量指标

基于GB/T国家标准计算以下指标：
- 电压偏差 (GB/T 12325), 限值 ±7%
- 电压THD (GB/T 14549), 限值 5%
- 电流THD (GB/T 14549), 限值 8%
- 三相电压不平衡度 (GB/T 15543), 限值 2%
- 频率偏差 (GB/T 15945), 限值 ±0.5Hz
- 变压器负载率, 限值 100%
- 线路载流量, 限值 100%
- 功率因数

## 使用方法

### 1. 运行默认场景仿真
```matlab
% 在MATLAB命令窗口中运行
main_setup
```
默认执行 **S4 - 光充耦合接入场景**，包含仿真、分析、指标计算、结果保存完整流程。

### 2. 运行指定场景
```matlab
main_setup('S1')   % 纯常规负荷基准
main_setup('S2')   % 充电桩接入
main_setup('S3')   % 分布式光伏
main_setup('S4')   % 光充耦合 (默认)
main_setup('S5')   % 极端高渗透率
```

### 3. 批量运行全部场景并生成对比报告
```matlab
main_setup('all')
```
输出包含场景对比汇总表和越限统计。

### 4. 运行蒙特卡洛风险评估
```matlab
main_setup('monte_carlo')
```
默认执行1000次采样，输出各指标越限概率及概率分布直方图。

### 5. 生成AI训练数据集
```matlab
main_setup('dataset')
```
默认生成10000条带标签样本，包含5类场景波形及20维特征向量。

### 6. 执行完整评估流程
```matlab
main_setup('full')
```
依次执行：全部场景仿真 → 蒙特卡洛分析 → AI数据集生成。
